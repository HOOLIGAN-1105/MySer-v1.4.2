## Описание

MySer — комплексный WordPress-плагин для управления сервисным центром по ремонту электроники. Обеспечивает полный цикл работы: от приёма заказа до выдачи готового устройства клиенту.

### Основные возможности

- **Управление заказами** — создание, редактирование, отслеживание статусов ремонта
- **База клиентов** — хранение контактных данных и истории обращений
- **Услуги и цены** — настраиваемый каталог услуг с гибкой системой цен
- **Сотрудники** — учёт мастеров и их загрузки
- **Финансы** — начисления сотрудникам, зарплатные сетки
- **Подразделения** — поддержка нескольких филиалов с реквизитами
- **Дашборд** — сводка по заказам и статистика
- **Резервное копирование** — экспорт/импорт данных (SQL, CSV/ZIP, MDB)
- **Оформление** — настраиваемые цвета и шрифты интерфейса
- **Онлайн-запись** — шорткод для публичной формы записи на ремонт
- **Логирование** — отслеживание ошибок и действий

## Требования

### Серверные требования
- **PHP:** 8.0 или выше
- **WordPress:** 6.5 или выше
- **MySQL:** 5.6 или MariaDB 10.0+
- **Модули:** MySQLi, PDO, JSON, ZIP
- **Права:** на создание таблиц в БД и запись в `/wp-content/uploads/`

### Рекомендации
- Для работы с ZIP-архивами требуется расширение `zip`
- Для работы с MDB-файлами требуется расширение `mbstring`

## Установка

### Автоматическая установка (из репозитория WordPress)
1. Перейдите в **Плагины → Добавить новый**
2. В строке поиска введите **MySer - Сервисный центр**
3. Нажмите **Установить**, затем **Активировать**

### Ручная установка (из ZIP-архива)
1. Скачайте архив плагина `MySer_1.2.3.zip`
2. В админке WordPress перейдите: **Плагины → Добавить новый → Загрузить плагин**
3. Выберите ZIP-архив и нажмите **Установить**
4. Активируйте плагин

### Установка через FTP
1. Распакуйте архив на локальном компьютере
2. Загрузите папку `myser` в `/wp-content/plugins/` на сервере
3. Активируйте плагин через админ-панель WordPress

**При активации** плагин автоматически:
- Создаёт все необходимые таблицы в базе данных
- Добавляет начальные данные (статусы заказов, роли)
- Создаёт папки для хранения бекапов и логов

## Настройка

Все настройки плагина находятся в разделе **MySer → Настройки**:

- **⚙️ Системные** — поведение при удалении, уровень логирования, название компании
- **Подразделения** — управление филиалами (название, реквизиты, банковские данные)
- **Заказы** — префикс заказа, сроки выполнения, уведомления
- **Финансы** — валюта, налоговая ставка, зарплатные сетки
- **Оформление** — основной цвет, шрифт, количество строк в таблицах

## Использование

### Управление заказами

1. Перейдите в **MySer → Заказы**
2. Нажмите «Добавить заказ»
3. Заполните данные клиента, устройства и выбранных услуг
4. Отслеживайте статус заказа на протяжении всего ремонта

### Онлайн-запись

Используйте шорткод `[myser_booking]` на любой странице для размещения публичной формы записи.

### Резервное копирование

1. Перейдите в **MySer → Бекапы**
2. Выберите формат экспорта (SQL, CSV/ZIP, MDB)
3. Нажмите «Создать бекап»
4. Для восстановления используйте кнопку «Импорт»

## Для разработчиков

### Хуки и фильтры

Плагин использует стандартные хуки WordPress:
- `admin_post_myser_reboot_plugin` — обработка ребута
- `wp_ajax_myser_*` — все AJAX-обработчики (с префиксом `wp_ajax_`)

### Логирование

Логи пишутся через класс `MySer\Logger`. Уровни:
- `debug` — отладочная информация
- `info` — информационные сообщения
- `warning` — предупреждения
- `error` — ошибки
- `critical` — критические ошибки

Настройка уровня логирования доступна в админке (вкладка «Системные»).

### Расширение плагина

Для добавления новых модулей:
1. Создайте класс-обработчик в `lib/includes/ajax/class-ajax-{module}.php`
2. Унаследуйте от `Ajax_Handler`
3. Реализуйте методы `register_actions()` и `handle_*()`
4. Зарегистрируйте обработчик в `Ajax_Handler::register_handlers()`

## Часто задаваемые вопросы

### Почему не создаются таблицы при активации?
Проверьте права пользователя БД. Нужны права `CREATE` и `ALTER`. Также убедитесь, что версия PHP соответствует требованиям.

### Как обновить плагин?
Скачайте новую версию и замените файлы через FTP, либо используйте автоматическое обновление из WordPress.

### Поддерживает ли плагин мультисайты?
Да, MySer полностью совместим с WordPress Multisite. Каждый сайт имеет свою базу данных.

### Можно ли импортировать данные из Excel?
Да, в разделе «Импорт/экспорт» доступна загрузка данных из CSV/Excel.
