# Руководство пользователя MySer

> Версия 1.3.3 | Для администраторов сервисных центров

---

## Начало работы

После установки и активации плагина в боковом меню WordPress появится раздел **MySer** со следующими пунктами:

1. **Дашборд** — общая статистика по заказам, клиентам, доходам
2. **Клиенты** — управление клиентской базой
3. **Заказы** — управление заказами на ремонт
4. **Сотрудники** — управление персоналом
5. **Подразделения** — управление филиалами и отделами
6. **Услуги** — каталог услуг
7. **Товары** — склад запчастей
8. **Статусы** — настройка статусов заказов
9. **Бекапы** — резервное копирование и восстановление
10. **Настройки** — конфигурация плагина

---

## Работа с клиентами

### Добавление клиента

1. Перейдите в **MySer → Клиенты**
2. Нажмите кнопку **Добавить клиента**
3. Заполните обязательные поля (ФИО, телефон, email)
4. Нажмите **Сохранить**

### Поля клиента

- **ФИО** — фамилия, имя, отчество
- **Телефон** — основной и дополнительный
- **Email** — электронная почта
- **Адрес** — фактический адрес
- **Тип** — физическое или юридическое лицо
- **Примечания** — дополнительная информация
- **Проблемный клиент** — отметка для особого контроля

### Поиск клиентов

Используйте поисковую строку для поиска по:
- ФИО
- Телефону
- Email
- ID

## Работа с заказами

### Создание заказа

1. Перейдите в **MySer → Заказы**
2. Нажмите **Создать заказ**
3. Выберите клиента из списка (или создайте нового)
4. Заполните информацию об устройстве
5. Добавьте услуги и товары
6. Установите статус
7. Нажмите **Сохранить**

### Поля заказа

- **Номер** — автоматически генерируется
- **Клиент** — выбор из базы
- **Устройство** — тип, производитель, модель, серийный номер
- **Жалоба клиента** — описание проблемы
- **Услуги** — список услуг с ценами
- **Товары** — запчасти и материалы
- **Статус** — текущий статус выполнения
- **Общая стоимость** — рассчитывается автоматически

### Изменение статуса

Статус заказа можно изменить:
- Через редактирование заказа
- Быстрым действием в списке заказов

## Работа с сотрудниками

### Добавление сотрудника

1. Перейдите в **MySer → Сотрудники**
2. Нажмите **Добавить сотрудника**
3. Заполните личную информацию
4. Настройте должность и подразделение
5. Укажите зарплатную сетку
6. Назначьте роли доступа
7. Нажмите **Сохранить**

### Поля сотрудника

- **ФИО** — полное и краткое
- **Контакты** — телефоны, email
- **Личные данные** — дата рождения, паспорт, адреса
- **Рабочие данные** — должность, подразделение, дата начала работы
- **Финансы** — оклад, проценты за услуги и товары
- **Роли** — права доступа к разделам

### Зарплатные сетки

Настройка процентов для расчёта зарплаты:
1. Перейдите в **MySer → Сотрудники → Зарплатные сетки**
2. Нажмите **Добавить сетку**
3. Укажите название и процент
4. Назначьте сетку сотруднику

---

## Управление подразделениями

### Создание подразделения

1. Перейдите в **MySer → Подразделения**
2. Нажмите **Добавить подразделение**
3. Заполните информацию о подразделении
4. Настройте реквизиты
5. Сохраните изменения

### Настройки подразделения

- **Название** — краткое и полное
- **Префикс заказа** — для генерации номеров
- **Адрес** — юридический и фактический
- **Контакты** — телефон, email
- **Реквизиты** — ИНН, КПП, ОГРН
- **Банковские реквизиты** — счёт, БИК
- **Руководитель** — ФИО и должность
- **Тип** — головное, филиал, удалённый

## Каталог услуг и товаров

### Услуги

Услуги — это виды работ, которые выполняет сервисный центр.

**Поля услуги:**
- Название
- Описание
- Цена
- Категория

### Товары (Запчасти)

Товары — это запчасти и расходные материалы.

**Поля товара:**
- Название
- Артикул (SKU)
- Цена
- Количество на складе

## Статусы заказов

Статусы помогают отслеживать этапы выполнения заказа.

### Создание статуса

1. Перейдите в **MySer → Статусы**
2. Нажмите **Добавить статус**
3. Введите название и выберите цвет
4. Нажмите **Сохранить**

### Цветовая индикация

Каждый статус имеет цвет для визуального отображения:
-  Зелёный — завершённые
-  Жёлтый — в процессе
-  Красный — проблемные
-  Синий — ожидают
- ⚫ Серый — архивные

## Резервное копирование

### Создание бекапа

1. Перейдите в **MySer → Бекапы**
2. Выберите формат экспорта:
   - **SQL** — чистый SQL-дамп
   - **CSV/ZIP** — архив с CSV-файлами
   - **MDB** — экспорт в формат Access
3. Нажмите **Создать бекап**

### Восстановление из бекапа

1. Перейдите в **MySer → Бекапы**
2. Нажмите **Импорт**
3. Выберите файл бекапа
4. Нажмите **Восстановить**

### Импорт CSV в Microsoft Access

3. Для каждой таблицы выполните импорт:

Файл: wp_myser_clients.csv  
- В Access: Внешние данные → Импорт из текстового файла
- Выберите CSV-файл
- Укажите, что файл содержит разделители (запятые)
- Отметьте 'Первая строка содержит заголовки'
- Назначьте таблице имя wp_myser_clients
- При необходимости укажите ключевые поля

## Настройки

В разделе **Настройки** можно сконфигурировать:

### Системные настройки

- **Название компании** — отображается в документах
- **Телефон поддержки** — для клиентов
- **Email поддержки** — для уведомлений
- **Уровень логирования** — debug, info, warning, error, critical
- **Поведение при удалении** — сохранять или удалять данные

### Уведомления

- **Email уведомления** — оповещения о статусах заказов
- **Шаблоны писем** — настройка текста уведомлений

### Импорт/Экспорт

- **Импорт клиентов** — из CSV/Excel
- **Экспорт данных** — выгрузка в CSV/Excel

### Безопасность

- **Права доступа** — настройка ролей
- **Логирование** — запись действий пользователей

## Часто задаваемые вопросы

### Как импортировать клиентов из Excel?
1. Подготовьте файл в формате CSV/Excel
2. Перейдите в **MySer → Клиенты → Импорт**
3. Выберите файл и укажите соответствие колонок
4. Нажмите **Импортировать**

### Как создать печатную форму заказа?
1. Откройте карточку заказа
2. Нажмите **Печать**
3. Выберите шаблон печатной формы
4. Нажмите **Скачать PDF** или **Печать**

### Как настроить автоматические уведомления?
1. Перейдите в **MySer → Настройки → Уведомления**
2. Включите нужные типы уведомлений
3. Настройте шаблоны писем
4. Сохраните изменения

### Как сделать резервную копию?
1. Перейдите в **MySer → Бекапы**
2. Нажмите **Создать бекап**
3. Дождитесь завершения процесса
4. Скачайте архив с бекапом
